## Run

```sh
python -m clinical_trial.synthetic_study local-data/new-study.json
python -m clinical_trial.comparison reference-rows.json candidate-rows.json local-data/comparison.json --seed 42
```

Output files must be new. Each paired row must provide patient_id, trial_id,
criterion_id, kind, gold, predicted, evidence_correct (explicit boolean), measured
latency_ms and cost_usd. Different cases, duplicate identities or conflicting gold
labels/polarity are rejected. Deltas are candidate minus reference. Report coverage
alongside false no-barrier assertions per criterion so increased abstention is
visible. Conditional error rates are also retained by the underlying evaluator.

Bootstrap resamples patients while keeping paired rows together, uses seed 42,
and returns no interval for a single patient. It does not account for shared-trial
dependence; use an appropriate study design before making generalization claims.

The ablations are intentionally weaker research configurations. `without_temporal`
ignores measurement assessment-date matching and treats an event on any valid date
as positive. `without_missing_evidence_control` treats an unresolved event window
as negative after syntax validation. Other controls remain active. They are
available to the offline experiment runner only, not through HTTP request fields.

## Evidence and limitations

The committed artifact in experiments/artifacts/synthetic-controls.json was
generated by running the study. Its planner is scripted, with zero provider calls
and zero model cost. Latencies are measured local runtime values and vary across
reruns; fixture hashes, labels, predictions and seeded intervals are reproducible.
The six cases deliberately cover recent/old/future events, absent history, partial
coverage and complete absence. Each uses a distinct synthetic patient and trial.

Fixture labels are authored expectations. The `evidence_correct` field in this
artifact is fixture label agreement only, explicitly marked in its metadata;
it is not expert evidence adjudication. These results validate software behavior,
not the research hypothesis on real trials or patients. Do not cite their apparent
accuracy as clinical performance. No paid model, Azure deployment, licensing
clearance, publication result, browser acceptance or expert review is claimed.

Validation: 117 Python tests, existing JavaScript DOM checks and Gunicorn runtime
smoke, study CLI execution, compilation and repository hygiene checks.
